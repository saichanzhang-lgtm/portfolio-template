# 个人作品集网页模板

一个**对话式生成**的个人作品集 / 求职主页 —— 面向秋招、实习、找工作。
把简历里说不清的东西，变成一个「能点开看」的地方。

> 灵感来自我自己的求职经历：简历最后一行附上作品集链接，面试官真的会点开。
> 模板由小红书「**乱码葱花饼**」整理，可自由使用、修改、分享。

## ✨ 特色

- 🎨 **设计完整**：首屏 / 关于 / AI 产品 / 自媒体 / 项目案例 / 实习 / 获奖 / 联系方式，六大板块开箱即用
- ✏️ **可视化编辑**：打开页面按 `Ctrl + Shift + E`（Mac 用 `Cmd`），不写代码就能改内容
- 🌐 **中英双语**：右上角一键切换
- 📱 **响应式**：手机端同样好看
- ☁️ **免费上线**：拖进 Cloudflare Pages 就能得到网址，0 成本
- 🤖 **AI 友好**：全站内容是结构化的，随便找个 AI 就能帮你改（见下方「用 AI 改」）

## 🚀 快速开始（3 步）

### 第 1 步：预览

下载本项目 → 解压 → 双击 `index.html`（或把文件拖进浏览器）。

### 第 2 步：改成你自己的

两种方式，随便挑：

**方式 A · 可视化编辑（推荐新手）**
1. 页面打开后按 `Ctrl + Shift + E`
2. 在编辑面板里按标签页改文字、增删条目（首屏 / 关于 / 作品集 / 实习 / 获奖 / 博客 / 联系）
3. 点「保存」

**方式 B · 直接改数据**
打开 `js/content.js`，把里面的【示例】内容替换成你自己的。

> ⚠️ **注意**：可视化编辑的改动只存在你**本机浏览器**里（刷新还在，换电脑就没了）。
> 要让**所有访客**都看到，点编辑面板的「导出JSON」，把内容贴回 `js/content.js`，再重新部署。

### 第 3 步：上线（免费，约 5 分钟）

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) 注册 / 登录（免费，无需信用卡）
2. 左侧菜单 → **Workers 和 Pages** → **创建** → **Pages** → **上传资产**
3. 把本项目**整个文件夹**拖进去 → 点部署
4. 拿到网址：`https://你的项目名.pages.dev` —— 把它写进简历最后一行就行 ✅

> 想用自己的域名？在 Pages 项目里添加自定义域名即可（域名本身需自费）。

## 📁 目录结构

```
├── index.html      ← 页面结构（一般不用改）
├── 404.html        ← 404 页面
├── favicon.svg     ← 网站图标
├── css/
│   ├── style.css   ← 页面样式（配色在这里改）
│   ├── admin.css   ← 编辑面板样式
│   └── fonts.css   ← 自托管字体样式（脚本生成，勿手改）
├── fonts/          ← 中文字体子集（自托管，国内访问稳定，不依赖 Google Fonts）
├── js/
│   ├── content.js  ← ⭐ 内容数据源（改这里 = 改全站内容）
│   ├── app.js      ← 渲染与交互逻辑
│   └── admin.js    ← 可视化编辑面板
└── images/         ← 图片（占位图直接替换成你的照片/截图）
```


## ❓ 常见问题

- **改了内容刷新没变化？** 如果用的是编辑面板，改动存在浏览器本地；确认已点「保存」，或改用 `js/content.js` 方式改。
- **想换图片？** 把图片放进 `images/`（建议压缩一下），在 `content.js` 里改对应路径。
- **为什么字体文件夹有 26MB？** 中文网页字体的常见问题：这里做了按需下载的子集化（448 个 woff2，只加载用到的字），国内打开快且不依赖外部服务。
- **部署后别人看不到最新内容？** 重新执行「上传资产」即可（Cloudflare 会生成新版本）。
- **没有自媒体账号，那个板块能删吗？** 可以，在 `index.html` 里删除 `<section ... id="media">` 整段。
